# Report Generator

A production-ready SaaS web app for capturing daily job/project progress —
activities, issues, manpower, equipment, materials, photos, and supporting
documents — and compiling it into professional, multi-section reports over a
selected project and date range.

**Stack:** Next.js (App Router) · Vercel · Supabase (PostgreSQL, Auth, Storage, Realtime)
